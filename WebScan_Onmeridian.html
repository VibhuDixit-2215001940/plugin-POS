HSTS Missing From HTTPS Server (Severity: Medium)

Finding Details

Plugin ID RFC Protocol / Reference Status Code Cache-Control Expires Max Age
142960 RFC -6797 RFC 6797 (HTTP Strict Transport Security) 403 no-cache Thu, 01 Jan 31536000

Description: The remote HTTPS server does not send the Strict-Transport-Security (HSTS) header, leaving users susceptible to SSL-stripping and MitM attacks.

Analysis Result: The Strict-Transport-Security header was not found on onmeridian.com. Browsers will not enforce HTTPS, exposing users to SSL-stripping attacks.

Remediation:

  • Add the following response header to your HTTPS web server configuration:
    Strict-Transport-Security: max-age=31536000; includeSubDomains; preload
  • Set max-age to at least 31536000 (1 year) as recommended by RFC 6797.
  • Include the includeSubDomains directive to protect all subdomains.
  • Submit the domain to the HSTS Preload List for maximum protection.
  • Ensure all HTTP traffic is redirected to HTTPS before deploying HSTS.
  • Reference: MDN — Strict-Transport-Security
